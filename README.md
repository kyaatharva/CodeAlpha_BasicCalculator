# Basic Calculator in C

This project is a basic calculator written in C.

## Features

- Addition
- Subtraction
- Multiplication
- Division

## Concepts Used

- Variables
- Input and output
- Switch case
- Conditional statements
- Arithmetic operators

## How to Run

Compile the program using:

```bash
gcc calculator.c -o calculator
```

Run it using:

```bash
./calculator
```
